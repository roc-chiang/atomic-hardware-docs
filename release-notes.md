# Release Notes & Version History

All updates to the **Atomic Forge Commerce** framework conform to semantic versioning rules (`vMAJOR.MINOR.PATCH`).

---

## v1.0.0 (2026-06-04) - Initial Gold Master Release

This is the initial commercial release of the **Atomic Forge Commerce** multi-industry framework, optimized for Online Store 2.0.

### Major Features
- **Brand Personality System (Presets)**: Core support for 5 brand settings (Atomic/Tactical, Industrial, Audio, Outdoor, Premium) dynamically controlling accent styles and copywriting vocabulary.
- **HUD Detailing Density Controls**: Three toggles (`minimal`, `standard`, `tactical`) to calibrate structural scanner visuals, CRT overlays, and grids.
- **17 Custom Section Templates**: Expanded block marketplace including Alpine.js Metallurgical Explorers, Blueprint blueprints, Milestones, and stockist grids.
- **Shopify Markets Compatibility**: Native multi-language and multi-currency conversions integrated into the HUD receiver dials.
- **Advanced Performance Features**: Dynamic WebGL 3D views, progressive LQIP laser image loading, and Microsoft Clarity tracking layers.
- **Full Mobile Optimization**: Form inputs, select dropdowns, and button margins fixed to a standard `h-[40px]` and `text-base` layout to suppress iOS input scaling issues.
