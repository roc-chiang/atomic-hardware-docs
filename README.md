# Atomic Hardware Docs

> Documentation hub for Atomic Hardware Shopify stores — design system, theming guides, and product page references.

---

## English

Atomic Hardware Docs is the documentation repository serving Shopify stores for PARDPRO's hardware products, including **Sodiumfrostglow** (the world's first sodium-ion flashlight, successfully crowdfunded on Kickstarter). This repository provides comprehensive guides for Shopify theme customization, product page design systems, and metafield management.

The documentation covers a Precision Commerce Design System for consistent product presentation, detailed metafield configuration guides, quick-start instructions for new store setups, section-based theming guides, support documentation, and release notes tracking all store updates.

Whether you're setting up a new Shopify store for a hardware product or customizing an existing theme, these docs provide the design system foundation and step-by-step instructions needed to maintain a consistent, high-quality e-commerce experience.
